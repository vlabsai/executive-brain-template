# Execuções e alterações observadas

Crie um registro por execução ou revisão relevante com [templates/run-log.md](../templates/run-log.md). Use data e um nome curto no arquivo.

Registre o que efetivamente ocorreu: ambiente, fontes consultadas, cobertura, saída, revisão e pendências. Um plano não é uma execução. Não inclua credenciais nem exportações completas. Nenhuma execução está registrada no template.
