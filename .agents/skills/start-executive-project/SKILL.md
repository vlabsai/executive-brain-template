# Preparar meu contexto

Siga [AGENTS.md](../../../AGENTS.md). Trabalhe na cópia do cliente já preparada pelo Codex; confira o destino antes de salvar. Se estiver no upstream comum, use o [pedido de preparação](../../../README.md#começar-pela-conversa). A entrevista não cria forks, clona repositórios ou muda acessos. Um ensaio explicitamente fictício pode usar uma pasta isolada sem Git.

Leia contexto.md e aproveite o que a pessoa já contou. Explique brevemente que vai entender sua rotina e salvar um contexto reutilizável. Pergunte pelo que ainda falta, normalmente uma questão por vez:

- Qual é seu papel e pelo que responde?
- Qual dificuldade de informação ou trabalho quer resolver primeiro?
- Pode contar um caso recente e onde estavam as informações?
- Que resultado pequeno faria diferença?
- Como prefere receber ajuda e o que podemos guardar nesta cópia?

Use essas perguntas como apoio, sem repetir respostas. Esclareça ambiguidades que mudam o objetivo. Detalhes desnecessários para começar ficam pendentes.

Mostre uma síntese e aproveite a conferência que a pessoa já tiver dado. Preencha contexto.md com papel, dificuldade, objetivo, preferências, origem e revisão. Preserve um trecho permitido em inbox/relato-inicial.md; reutilize uma fonte já fornecida em vez de duplicá-la. Use links relativos para ligar contexto e origem. Preserve conteúdo existente que não foi alterado.

Se faltar conferência, identifique o conteúdo como rascunho. Mostre os arquivos realmente salvos e uma informação da conversa em cada um. Não crie configurações, cadastros ou registros extras para essa entrevista. Não faça commit ou push de dados pessoais. A próxima atividade é organizar uma informação do trabalho com a skill de curadoria.
